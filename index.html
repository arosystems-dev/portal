PUBLICACIONES

Introducción al Desarrollo Web Full Stack

Curso diseñado para quienes desean iniciarse en el desarrollo de aplicaciones Web Full Stack, abordando desde el análisis y diseño de soluciones hasta la implementación de frontend, backend y bases de datos. Las aplicaciones CRUD desarrolladas en este curso, fuerón actualizadas y liberadas en GitHub. Para ver y revisar el material, ingrese a la sección CURSOS - Desarrollo Web.

(Curso dictado en CIPEC durante la gestión 2023)

Desarrollo Web desde cero

Curso básico dirigido a personas que desean aprender a desarrollar aplicaciones web desde cero. El curso introduce progresivamente los fundamentos de HTML5, CSS3 y JavaScript, para posteriormente abordar el desarrollo de proyectos web completos mediante la integración de Frontend, Backend y Bases de Datos, desde el análisis y diseño de soluciones hasta su implementación.

(Curso dictado en ITBOL durante la gestión 2022)

Microsoft Excel

Curso básico dirigido a personas que desean aprender a utilizar Microsoft Excel desde cero. El curso introduce progresivamente las herramientas y funciones fundamentales de Excel, para posteriormente abordar la creación y gestión de hojas de cálculo, aplicando fórmulas, funciones, formatos, tablas y gráficos para la organización, análisis y presentación de información.

(Curso dictado en ITBOL durante la gestión 2021)
